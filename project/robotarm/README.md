# 로봇팔 제어 시스템 프로젝트 보고서

## 1. 프로젝트 개요

본 프로젝트는 웹 기반 3D 시뮬레이션과 실시간 영상 스트리밍을 통해 로봇팔을 제어하는 시스템을 구축하는 것을 목표로 합니다. 사용자는 웹 브라우저에서 로봇팔의 움직임을 3D로 확인하고, ESP32 컨트롤러의 조이스틱으로 로봇팔을 직접 조작할 수 있습니다. 또한, 라즈베리파이에 연결된 카메라를 통해 실시간 영상을 확인하고 원격으로 사진 촬영이 가능합니다.



## 2. 시스템 아키텍처

본 시스템은 크게 세 가지 주요 부분으로 구성됩니다.

* **웹 사용자 인터페이스 (Client - `html.txt`)**: 사용자와 상호작용하는 프론트엔드입니다. Three.js를 사용하여 로봇팔을 3D로 시각화하고, Web Serial API를 통해 ESP32 컨트롤러와 직접 통신합니다. 또한, 라즈베리파이로부터 MJPEG 영상 스트림과 WebSocket 신호를 수신합니다.
* **ESP32 조이스틱 컨트롤러 (`esp32.txt`)**: 두 개의 조이스틱 입력을 받아 JSON 형식의 데이터로 변환하고, 이를 USB 시리얼 통신을 통해 웹 인터페이스에 전송하는 역할을 합니다.
* **라즈베리파이 서버 (`main.txt`)**: 시스템의 핵심 백엔드입니다. Picamera2를 이용해 MJPEG 영상 스트리밍 서버를 운영하고, WebSocket 서버를 통해 사진 촬영과 같은 이벤트를 웹 인터페이스에 알립니다. 또한, 물리적 버튼(GPIO) 입력을 감지하여 사진 촬영 명령을 수행합니다.

### 데이터 흐름

1.  **제어 신호**: `ESP32` → (USB Serial) → `웹 브라우저`
2.  **3D 시뮬레이션**: `웹 브라우저`에서 제어 신호를 받아 Three.js 모델 업데이트
3.  **영상 스트리밍**: `라즈베리파이` → (HTTP MJPEG) → `웹 브라우저`
4.  **이벤트 알림**: `라즈베리파이` → (WebSocket) → `웹 브라우저`

## 3. 핵심 구성 요소 및 기능

### 가. 웹 사용자 인터페이스 (`html.txt`)

* **3D 시뮬레이션**: Three.js 라이브러리를 사용하여 로봇팔의 4개 관절(J1-J4)과 그리퍼의 움직임을 실시간으로 렌더링합니다.
* **실시간 데이터 표시**: 로봇팔의 각 관절 각도와 그리퍼 상태를 UI에 숫자로 표시합니다.
* **컨트롤러 연결**: Web Serial API를 사용하여 브라우저에서 직접 ESP32 컨트롤러의 COM 포트에 연결하고 데이터를 수신합니다.
* **실시간 영상 확인**: 라즈베리파이 서버에서 송출하는 MJPEG 스트림을 `<img>` 태그를 통해 받아와 사용자에게 보여줍니다.
* **사진 촬영 알림**: 라즈베리파이의 WebSocket 서버로부터 'picture_taken' 메시지를 받으면, 영상 테두리에 하이라이트 효과와 함께 알림 텍스트를 표시하여 사용자 경험을 향상시킵니다.

### 나. ESP32 조이스틱 컨트롤러 (`esp32.txt`)

* **하드웨어**: 2개의 조이스틱 모듈과 1개의 스위치가 연결된 ESP32 보드를 사용합니다.
* **데이터 처리**: 각 조이스틱의 X, Y축 아날로그 값을 읽고, 데드존(Deadzone)을 적용하여 미세한 떨림을 방지합니다.
* **데이터 형식**: 읽어들인 조이스틱 값과 스위치 상태를 아래와 같은 JSON 형식으로 만들어 시리얼 포트로 전송합니다.
    ```json
    {
      "j1x": 2048,
      "j1y": 2048,
      "j2x": 2048,
      "j2y": 2048,
      "j2sw": 0
    }
    ```
* **통신**: 115200 baud rate로 50ms마다 (20Hz) 데이터를 전송하여 부드러운 제어가 가능하도록 합니다.

### 다. 라즈베리파이 서버 (`main.txt`)

* **언어 및 라이브러리**: Python, `asyncio`, `websockets`, `picamera2`, `gpiod`를 사용합니다.
* **MJPEG 영상 스트리밍**: Picamera2 라이브러리로 카메라 영상을 Jpeg으로 인코딩하고, 이를 HTTP 서버를 통해 `multipart/x-mixed-replace` 형식으로 실시간 스트리밍합니다.
* **WebSocket 서버**: 웹 클라이언트와의 양방향 통신 채널을 유지합니다. GPIO 버튼이 눌려 사진 촬영이 완료되면 연결된 모든 클라이언트에게 `picture_taken` 메시지를 브로드캐스트합니다.
* **GPIO 버튼 입력**: 라즈베리파이의 GPIO 핀에 연결된 물리적 버튼의 입력을 감지합니다. 디바운싱(Debouncing) 로직을 적용하여 버튼이 한 번만 인식되도록 처리하고, 버튼이 눌리면 `take_picture()` 함수를 호출합니다.
* **멀티스레딩**: HTTP 서버, WebSocket 서버, GPIO 모니터링이 동시에 동작할 수 있도록 `threading`과 `asyncio`를 함께 사용합니다.

## 4. 결론

본 프로젝트는 Web Serial API, WebSocket, MJPEG 스트리밍 등 최신 웹 기술과 임베디드 시스템(ESP32, 라즈베리파이)을 성공적으로 결합하여 직관적이고 반응성이 뛰어난 원격 로봇팔 제어 시스템을 구축했습니다. 각 컴포넌트는 명확한 역할을 가지고 독립적으로 동작하며, 표준화된 프로토콜(JSON, HTTP, WS)을 통해 효율적으로 통신합니다. 이를 통해 확장성과 유지보수성이 높은 시스템을 완성했습니다.
